# J2P — Jw_cad 一括PDF変換ツール

Jw_cad（.jww）の図面を複数まとめてPDFへ変換するWindows用デスクトップアプリです。
Jw_cadの「印刷 → PDF保存」の手作業を自動化し、提出前の大量の図面を短時間でPDF化します。

- **Jw_cad本体のインストール不要** — JWWファイルを直接解析して自前でPDFへ描画します
- **印刷範囲を再現** — ファイルに保存された印刷範囲原点・印刷倍率・90°回転出力を読み取り、Jw_cadで設定した印刷範囲どおりに出力します（用紙全体／図形フィットへの切り替えも可能）
- 数十〜数百枚の一括処理を想定した逐次パイプライン（一時停止・再開・中止対応）

## 主な機能

| 分類 | 内容 |
|---|---|
| ファイル選択 | 複数選択・フォルダ単位（サブフォルダ含む切替）・ドラッグ＆ドロップ |
| ファイル一覧 | ファイル名／フォルダ／更新日時／用紙サイズ／縮尺／出力予定PDF名／変換状態。列ソート・検索 |
| 出力先 | 元ファイルと同じフォルダ／指定フォルダ |
| PDF設定 | 用紙（自動・A4〜A0）／向き（自動・縦・横）／倍率（自動・100・70・50・任意%）／白黒・カラー |
| 出力名 | 元ファイル名／_PDF付き／_日付付き／任意パターン（`{name}` `{date}` `{time}`） |
| 同名時 | 上書き／連番／スキップ |
| 一括変換 | 処理中ファイル・全体進捗・残数・成功数・エラー数を表示。一時停止／再開／中止 |
| エラー処理 | 失敗ファイルと理由の一覧、最後に成功／失敗サマリを表示 |
| ログ | 開始・終了時刻／処理時間／件数／エラー内容をテキスト保存 |
| オプション | サブフォルダ処理／更新ファイルのみ／変換後にフォルダ・PDFを開く／PDF結合／事前確認画面 |
| UI | 一画面完結・ダークモード・設定の自動保存 |

## ダウンロード / ビルド

GitHub Actions の `App publish (Windows exe)` ジョブが単一exe（`J2P.exe`、自己完結型）を成果物として生成します。

手元でビルドする場合（Windows / .NET 8 SDK）:

```powershell
dotnet publish src/J2P.App -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true -o publish
```

コアライブラリとテストはクロスプラットフォームです:

```bash
dotnet test tests/J2P.Core.Tests
```

## 構成

```
src/J2P.Core   JWWパーサ（MFC CArchive互換リーダ）・PDFレンダラ・変換パイプライン（UI非依存）
src/J2P.App    WPF UI（.NET 8 / MVVM / ライト・ダークテーマ）
tests/         xunit テスト（Linuxでも実行可能）
```

## 既知の制限（v1）

- 埋め込み画像・画像参照文字（`^@BM…`）は描画されません（警告としてログに記録）
- ランダム線・倍長線種は実線で近似されます
- 文字はBIZ UDゴシック / BIZ UD明朝（同梱・SIL OFL）で描画されるため、MSゴシック等の見た目と微差があります
- ソリッドの頂点順・特殊線種の破線ピッチなどは実図面での検証を継続中です
